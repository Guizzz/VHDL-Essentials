# Commands

All commands are accessible via the Command Palette (`Ctrl+Shift+P`).

| Command ID | Title | Description |
|---|---|---|
| `quartus-assistant.build` | Quartus: Build | Run `quartus_sh --flow compile` |
| `quartus-assistant.flash` | Quartus: Flash | Run `quartus_pgm` for device programming |
| `quartus-assistant.generateDo` | Quartus: Generate QuestaSim DO | Generate `.do` simulation script for testbench |
| `quartus-assistant.runDo` | Quartus: Run QuestaSim | Launch `vsim` with the selected `.do` file |
